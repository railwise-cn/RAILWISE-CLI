# RAILWISE Desktop Codex-Style Harness + Marketplace Redesign Implementation Plan

This branch implements the Codex-style RAILWISE Desktop redesign around four product primitives:

- Workbench: workspace-first, chat-first main surface.
- Harness: visible runtime state, tool timeline, permissions, artifacts.
- Marketplace: installable and enableable Agents, Tools, Skills, Workflows, MCP Connectors, Model Providers, Harness Profiles.
- Desktop startup: launch directly into the workbench, not the old Agent Studio dashboard.

Implementation source of truth is the detailed plan drafted on 2026-05-23. This branch keeps this summary in-tree so the feature work has a durable reference while the main implementation is split into focused commits.
