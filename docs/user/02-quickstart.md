# 5 分钟上手

## 选择项目文件夹

打开 RAILWISE Desktop 后进入多智能体 Harness 工作台。先在左侧选择或输入项目文件夹，智能体会把该目录作为本次会话的工作上下文。

## 接入模型

默认建议接入 DeepSeek V4，也可以通过 OpenRouter 或 OpenAI 兼容 Provider 接入其他模型。不同专业智能体可以在配置页绑定不同模型。

## 发起智能体任务

在主输入框里描述工程任务，例如“检查当前线路复测资料，列出缺失文件、风险点和下一步执行计划”。选择项目总控或专业智能体后点击“开始”，系统会进入会话页，并在顶部显示 Harness 状态、能力数量、权限状态和工具运行状态。

## 使用能力市场

能力市场提供可启用的 Agents、Tools、Skills、Workflows、MCP Connectors、Model Providers 和 Harness Profiles。启用能力后，工作台和会话会按当前能力状态调度。

## 查看结果

智能体输出会显示在会话区，工具、权限和交付产物会进入 Harness 时间线。生成的报告、清单或审查结论可在会话中继续追问，也可进入交付包审阅和导出流程。
