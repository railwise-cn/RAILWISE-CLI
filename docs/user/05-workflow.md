# 工作流能力

工作流能力用于把多个专业智能体、工具和 Skills 串成工程流水线。典型流程是：资料检查 → 规范引用 → 平差/趋势分析 → 报告生成 → 合规审查。

## 运行预置流水线

1. 打开 Harness 工作台。
2. 在能力市场中启用需要的工作流、工具和 Skills。
3. 在项目文件夹会话中描述目标，例如“检查复测资料完整性并生成审查摘要”。
4. Harness 会把智能体调度、权限决策、工具事件和产物写入会话时间线。
5. 在会话区查看生成的报告、清单或 Markdown 交付摘要。

## 调整节点

每个工作流能力对应一组智能体、工具和完成标准。调整时优先修改输入、输出和质量闸门，避免把跨能力共享规则复制到每个智能体中。

## 失败处理

如果某个节点失败，可在会话中查看工具调用卡和错误信息。修复数据后重新运行当前流水线，或 Fork 到新会话继续处理。
