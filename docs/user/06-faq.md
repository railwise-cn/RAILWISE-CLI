# 常见问题

## 为什么启动后没有进入 Harness 工作台？

确认本机没有旧的 Web 预览页被误用。RAILWISE Desktop 应从桌面应用启动，默认落地页是 `/agents`，旧的 `/dashboard` 和 `/workspace` 地址会自动跳转到 Harness 工作台。

## 离线环境能否使用？

可以。Harness 工作台、项目文件夹和已安装能力可在本地打开；模型可切换到本地 Ollama 或企业内网模型服务。更新检查在离线环境会失败但不影响本地工作。

## 文件会上传吗？

桌面端优先本地读取文件。埋点默认关闭；启用后也只记录匿名 UI 计数和崩溃信息，不保存 Prompt 内容、项目名、文件名或文件路径。

## 自动更新失败怎么办？

先确认网络能访问更新服务器。企业内网用户请联系管理员确认私有更新服务器配置。也可以下载安装包覆盖安装。

## 是否有 Linux 桌面版？

暂不发布 Linux 桌面安装包。Linux 上的工程自动化和 CI 场景请使用 RAILWISE CLI。
