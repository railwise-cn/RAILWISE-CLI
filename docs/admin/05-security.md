# 安全与审计

## 数据本地化

RAILWISE Desktop 优先在本机处理工程文件。CSV、XLSX、DXF、PPTX、DOCX、PDF 预览由本地命令或桌面端解析完成。

## API Key

API Key 不应写入项目目录、提示词模板或智能体 Markdown。企业统一 Key 建议放在代理层，桌面端只配置代理地址。

## 埋点策略

埋点默认关闭。首次启动会询问是否启用，用户主动启用后，仅收集 UI 事件计数和崩溃信息。脱敏策略会移除 Prompt 内容、项目名、文件名、文件路径、Token 和密钥类字段。

Rust 崩溃上报通过 `RAILWISE_SENTRY_DSN` 注入 DSN。该变量为空时不上报，国内部署建议接入企业自建 Glitchtip。

## 审计建议

管理员应定期检查：

- 模型代理访问日志
- 私有更新服务器访问日志
- 安装包签名状态
- 内网分发目录权限
- 企业共享模板是否包含敏感信息
