# 业务模板

模板用于把常见工程任务固化为变量表单和 Prompt 队列项。打开模板抽屉后选择业务分类，填写字段并发送。

## 预置模板

| 模板 | 典型场景 |
| --- | --- |
| 外业数据首检 | 导入 CSV/XLSX 后检查缺测、异常值和字段一致性 |
| 沉降趋势分析 | 对监测点序列生成趋势判断和风险解释 |
| 监测月报 | 汇总项目概况、监测结论、告警和下阶段建议 |
| 项目汇报 PPT | 生成面向业主的阶段汇报演示稿 |
| 成果合规审查 | 对报告、表格和图纸成果做完整性检查 |
| 图纸说明生成 | 根据 DXF 图层和实体信息生成说明文本 |

## 自定义模板

模板由 JSON 描述：

```json
{
  "id": "custom-monitor-summary",
  "category": "report",
  "title": "自定义监测摘要",
  "agent": "report_writer",
  "variables": [
    { "key": "项目名称", "label": "项目名称", "type": "text" },
    { "key": "监测周期", "label": "监测周期", "type": "text" }
  ],
  "prompt": "请为{{项目名称}}生成{{监测周期}}监测摘要。"
}
```

变量内容会进入当前会话。请避免把身份证号、完整客户合同、原始 API Key 等敏感数据写入模板。
