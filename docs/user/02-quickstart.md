# 5 分钟上手

## 创建项目

打开 RAILWISE Desktop 后进入“项目驾驶舱”。点击“新建项目”，填写项目名称、类型和测区信息。项目卡片会显示健康度、告警数、最近活动与监测趋势。

## 导入资料

进入“数据工作台”，使用“打开文件”导入 CSV、XLSX、DXF、PPTX、DOCX 或 PDF。CSV/XLSX 会显示表格预览，DXF 会显示图层面板，Office/PDF 文件会进入成果预览。

## 发起智能体任务

在预览页点击“发送到智能体”，选择 qa_inspector、survey_analyst 或 ppt_master 等智能体。系统会把当前文件摘要和上下文放入会话，不上传本地文件路径或完整文件名到埋点。

## 使用业务模板

按 `Cmd/Ctrl + T` 打开模板抽屉，选择沉降分析、外业首检、汇报 PPT 等模板。填写变量后点击“发送”，任务会进入 Prompt 队列，可继续 Fork 或 Revert 会话。

## 查看结果

智能体输出会显示在会话区，工具调用卡片使用中文名称。生成的报告、PPT 或审查结论可在会话中继续追问，也可作为后续模板输入。
