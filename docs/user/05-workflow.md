# 工作流画布

工作流画布用于把多个智能体串成工程流水线。典型流程是：数据清洗 → 质量检查 → 趋势分析 → 报告生成 → 合规审查。

## 运行预置流水线

1. 打开“智能体编排台”或“工作流”入口。
2. 选择“监测报告流水线”。
3. 填写项目名称、周期和附件目录。
4. 点击运行，等待状态变为“已完成”。
5. 在输出文件区查看生成的 `.docx`、`.pptx` 或 Markdown 报告。

## 调整节点

每个节点对应一个智能体和一段任务说明。调整节点时优先修改输入、输出和完成标准，避免把跨节点共享规则复制到每个智能体中。

## 失败处理

如果某个节点失败，可在会话中查看工具调用卡和错误信息。修复数据后重新运行当前流水线，或 Fork 到新会话继续处理。
