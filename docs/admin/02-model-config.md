# 模型配置

RAILWISE Desktop 支持个人 Key、企业统一 Key 和本地模型三种模式。

## 个人 Key

用户在设置中连接模型供应商。该模式适合小团队试用，Key 保存在本机配置中。

## 企业统一 Key

管理员在企业网关或模型代理层统一配置 Key，桌面端只连接代理地址。推荐限制模型、速率和可访问网段。

```text
RAILWISE Desktop → 企业模型代理 → OpenAI / Anthropic / OpenRouter / 私有模型
```

## 本地模型

无外网环境推荐 Ollama 或兼容 OpenAI API 的本地服务。离线模式下模板和智能体仍可运行，但效果取决于本地模型能力。

## 安全要求

不要把 API Key 写入智能体提示词、业务模板或项目文件。共享电脑使用后请清理供应商配置和系统凭据。
