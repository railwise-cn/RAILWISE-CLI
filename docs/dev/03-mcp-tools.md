# MCP 工具接口

RAILWISE 的智能体工具面向工程测绘场景，工具名保持业务语义清晰，输出优先结构化。

## 数据类工具

| 工具              | 输入               | 输出                       |
| ----------------- | ------------------ | -------------------------- |
| rw_import_csv     | CSV 路径或上传引用 | 字段、行数、样例、异常摘要 |
| rw_trend_analysis | 监测点序列         | 趋势、阈值、风险等级       |
| rw_dxf_layers     | DXF 路径或解析结果 | 图层、实体统计、范围       |

## 成果类工具

| 工具                | 输入                 | 输出                 |
| ------------------- | -------------------- | -------------------- |
| rw_generate_docx    | Markdown 报告        | `.docx` 文件引用     |
| rw_generate_pptx    | 汇报结构与素材       | `.pptx` 文件引用     |
| rw_compliance_check | 报告、图纸、表格摘要 | 合规项、缺失项、建议 |

## 约束

工具不得把本地绝对路径泄露给模型。发送给模型的上下文应使用文件摘要、字段名、统计值和必要片段。
